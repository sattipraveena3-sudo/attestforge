# Security Policy

**Supported version:** 0.1.x (initial portfolio release).

For security issues, do not disclose exploit details in a public issue before a fix is available. Use GitHub private vulnerability reporting when enabled for this repository; otherwise contact the maintainer using the contact information on the public profile. Include a minimal reproduction, affected version, impact and proposed mitigation. Never send real private keys or customer data.

This is a research/portfolio implementation, not a security-certified product. Its trust model, threat boundaries and known limitations are documented in `docs/THREAT_MODEL.md`.
