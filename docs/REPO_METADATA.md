## First publication

The deliverable is a **complete local ZIP**, not an already-created GitHub repository. Create an empty public repository named `attestforge` under the GitHub account above, **without adding an autogenerated README/license**, then run from the extracted `attestforge/` directory:

```bash
git init -b main
git config user.name "Praveena Satti"
git add .
git status --short
git commit -m "feat: initial AttestForge release attestation platform"
git remote add origin https://github.com/sattipraveena3-sudo/attestforge.git
git push -u origin main
```

Never add `.local/`, private PEMs, `.env` files, secrets or real customer artifacts. The `.gitignore` excludes them, but check `git status --short` before pushing.

## Release after successful CI

```bash
git tag -a v0.1.0 -m "AttestForge v0.1.0: signed release manifests and policy gates"

```

## Verification before public announcement

```bash
python -m pip install -e '.[dev]'
make test
make lint
make smoke
docker build -t attestforge:ci .
bash scripts/docker_smoke.sh
```

The `v0.1.0` tag triggers `.github/workflows/release.yml`, which reruns lint/tests/smoke, builds Python distributions, and creates GitHub Release assets. Review the GitHub Actions runs after pushing.
